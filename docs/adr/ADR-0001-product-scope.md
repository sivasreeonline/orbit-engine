# ADR-0001: Product Scope

- Status: Accepted
- Decision: Build an Intelligent Coding Judge, scope B.
- Context: The product needs reliable execution plus assessment evidence, without attempting the full long-term coding intelligence platform in its first release.
- Consequences: M0 proves secure execution. M1 delivers problem management, editor integration, Run, Submit, test evaluation, verdicts and attempt history. Advanced AI coaching, interview simulation and predictive placement analytics are later milestones.
- Non-goals: replacing LeetCode, general-purpose IDE, unrestricted code hosting, or building a full microservice platform.
